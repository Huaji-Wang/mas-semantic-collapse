# 整帖运动分类：chik200

**样本**：文件顺序前 200 条合格 Reddit 帖；评论级 `bge-m3`；CPU  
**指标**：新 \(\chi=0.5(1-\cos\Delta\theta)\)；\(k\) 为余弦距离 0.55 的范围聚类  
**规则**：一条帖一个类。九行（去掉成丝）按整段走势软打分，取最高。不是旧的相邻步标签。

## 结果

| 类 | 帖数 | 占比 | 该类平均 \(S_{end}\) |
|---|---:|---:|---:|
| 平移 | 165 | 82.5% | 0.846 |
| 裂变 | 14 | 7.0% | 0.823 |
| 扩散 | 8 | 4.0% | 0.832 |
| 轨道 | 7 | 3.5% | 0.863 |
| 凝聚 | 5 | 2.5% | 0.802 |
| 级联 | 1 | 0.5% | 0.784 |
| 结晶 | 0 | 0 | — |
| 涡流 | 0 | 0 | — |
| 呼吸 | 0 | 0 | — |

分差中位 0.59，多数帖不是两类打成平手。

## 怎么读

主形态是 **平移**：云心离开开头，\(\sigma,d,k,\chi\) 的整段升降不够压过「搬走」。这和 Phase-1 只看 \(S_{end}\) 时「多数帖中心慢移」相容，但不能把它读成「人类讨论只有平移」——打分里平移对 \(m\) 离开给了较高权重，空类也可能是规则还没抓住冻住/内部转/呼吸。

新算法确实分开了几件旧标签做不到的事：

- **轨道 7 条**：\(m\) 先离开再回来，且 \(\chi(t)\) 也起浪。平均 \(S_{end}\) 最高（0.86），正是「结尾仍像开头、过程却绕过圈」。
- **裂变 14 条**：范围聚类的 \(k\) 上升，不是旧的整数 \(k\equiv 1\)。
- **结晶 / 涡流 / 呼吸为空**：\(\chi\) 逐步冻住、持续内部转、\(\sigma\) 与 \(\chi\) 一起呼吸，在这 200 条上没有赢过其他行。

旧匈牙利 \(\chi\) 不能做这张表：它几乎处处 0.83，波浪和冻住都没有。
