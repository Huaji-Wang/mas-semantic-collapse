## 2. \(\chi\) 在运动表里的角色

身份无关 \(\chi\) 在本批几乎处处偏高（中位 \(\approx 0.83\)）。若按原表要求 Translation 必须 \(\chi\) 稳定，则本语料上几乎贴不出 Translation。

**现行选择**：把偏高的 \(\chi\) 当作 Reddit 评论窗更替的背景。Translation **不**以 \(\chi\) 稳定为否决项。Crystallization 只在「\(\chi\) 处于样本下 20% **且** \(\sigma,d\)、二分强度稳定」时标记；该阈仍约 0.80，是相对低，不是 \(\chi\to 0\)。

## 3. 运动标签贴在哪一层

标签贴在相邻步 \(t-1\to t\)，不是整帖互斥一类。Orbit / Vortex / Breathing / Cascade 在本尺度标为**不可判定**。

可判别子集的互斥优先级：

结晶 \(\to\) 凝聚 \(\to\) 裂变代理 \(\to\) 成丝 \(\to\) 扩散 \(\to\) 平移 \(\to\) 换位背景

\(n=2814\) 步的第一版占比：换位背景 36.4%；凝聚 20.0%；扩散 15.4%；裂变代理 14.9%；平移 6.9%；结晶 5.4%；成丝 1.0%。凝聚/扩散接近所取分位尾部，**不能**直接读成过程频率。较站得住的三句是：主形态为换位背景；纯平移少见；成丝基本测不到。
